# Шаблон описания релиза

Заполняй разделы по фактическим изменениям и опубликованным файлам. Пустые разделы можно убрать; ограничения и требования к обновлению указывай, если они есть.

```markdown
## Что изменилось

- Изменение, заметное пользователю.

## Что исправлено

- Исправленная проблема.

## Что важно знать

- Ограничения, совместимость или действия при обновлении.

## Какой пакет скачать

- Arch Linux (x86-64): `имя опубликованного .pkg.tar.zst`.
- Ubuntu 24.04 (amd64): `имя опубликованного .deb`.
- Debian 13 (amd64): `имя опубликованного .deb`.

Добавь ссылку на инструкцию по установке для этого релиза.
```

Перечисляй только действительно опубликованные пакеты и проверенные архитектуры. Не меняй описания старых релизов ради соответствия шаблону.
